# HUMA — мини-приложение для MAX

Витрина продуктов Huma Marketing: онбординг, опрос ассистента, персональное предложение, магазин, кабинет, акции.

- Тексты, цены, тарифы, ссылки на оплату — `config.js`
- Цвета и шрифты — переменные в начале `styles.css`

Публикуется через GitHub Pages из ветки `main`.
